Keyword search matches exact words. Semantic search matches meaning.

When you search "best pizza NYC" with keywords, you only get pages
containing those exact words. Semantic search understands you want
*top-rated pizzerias in New York* and returns relevant results even
if they use different words to say it.

This is possible because semantic search uses **embeddings** —
numerical representations of meaning.

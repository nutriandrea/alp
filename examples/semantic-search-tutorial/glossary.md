| Term | Definition |
|------|------------|
| Embedding | A dense vector representation of text meaning |
| Cosine Similarity | Measure of similarity between two vectors (-1 to 1) |
| ANN | Approximate Nearest Neighbors — fast search for large indexes |
| FAISS | Facebook AI Similarity Search — library for efficient similarity search |
| sentence-transformers | Library for generating sentence embeddings |
| Query | The search input text |
| Corpus | The collection of documents to search over |
| Dimension | Length of the embedding vector (384 for MiniLM, 768 for mpnet) |

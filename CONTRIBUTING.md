# Contributing to ALP

ALP is an open standard. Contributions are welcome.

## How to Contribute

1. **Use ALP** — Create vaults, consume them with agents, report what works
2. **Report issues** — Bugs in the spec, confusing docs, missing features
3. **Build tools** — Extractors, validators, viewers, integrations
4. **Create examples** — Vaults for different domains (Python, math, design, etc.)
5. **Improve the spec** — PRs with clear rationale for changes

## What Makes a Good ALP Vault

- Clear prerequisites (what should the agent know first?)
- Atomic concepts (one idea per file, loadable independently)
- Progressive difficulty (easy → medium → hard)
- Verifiable practice (can the agent confirm it learned?)
- Concise content (agents have limited context — every sentence counts)

## Spec Evolution

ALP v0.1 is experimental. The spec will change based on real-world usage.
Don't be afraid to propose changes — the protocol is meant to evolve.
